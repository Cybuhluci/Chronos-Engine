# Echoes of The Eternity

Not a studio project. Not polished marketing copy. Just me messing around with a TARDIS flight toy because it's fun. If you want to pilot a box with six buttons and nothing else, welcome.

### Quick pitch
A tiny TARDIS flight simulator: you are a player with no visible body, standing inside a TARDIS that has a handful of working systems. Walk around, press buttons, and toy with the controls. Nothing dramatic happens yet.

### Core things to know
- Scope: Experimental prototype / toy. No story, no missions, no heists yet.  
- Player: You are a camera-controlled player with no body model in the current build.  
- TARDIS: Interior exists and about ten or so buttons have basic interactions implemented.
- Assets: Prototype assets and placeholders. Expect rough models and temporary sounds.  
- Spoilers: There isn't much to spoil, but the interactive scripts live in Assets/Scripts/Tardis - avoid if you want surprises.

### Controls & play notes
- Default controls: keyboard + mouse; WASD to move, mouse to look, F to interact with buttons.  
- Play focus: poke the TARDIS, test button interactions, sanity-check player movement and collision.  
- When reporting bugs: open an issue and include reproduction steps and a short video if possible.

### Status
